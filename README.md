# React assignments

Solutions to the [Exactspace React assignments](https://github.com/exact-space/react-assignments). Each app is self-contained in its own folder with its own README.

| App | What it is | Run |
| --- | --- | --- |
| [chat-app](chat-app) | Chat app with random usernames and like counts, plus emoji, @mentions and an Express + socket.io server | `cd chat-app`, `npm install`, `npm run dev`, open http://localhost:5173 |
| [photo-gallery](photo-gallery) | One column infinite scroll gallery over the picsum.photos feed with a Font Awesome thumbs-up counter per photo | `cd photo-gallery`, `npm install`, `npm run dev`, open http://localhost:5174 |

Both are built with React 18 and Vite, and need Node 18 or newer.
